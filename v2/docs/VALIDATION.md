# Проверки на 3 ноября 2026

## Новая основа

Среда: Node.js 24.22.1, npm 11.9.0, TypeScript 5.9.3, Zod 4.6.7. Зависимости v2 зафиксированы отдельно от старого приложения.

- `npm run check --prefix v2`: strict TypeScript прошёл, **38 тестов прошли**.
- Проверены: линейное воспроизведение, геометрия hotspot, повреждённые связи и неизвестные поля, ограничения метаданных изображений, очистка URL, закрепление записи за вкладкой/окном/origin, iframe, изменение документа и viewport во время capture, ограничение частоты после сериализации, гонка двух команд, идемпотентность, Stop во время capture, восстановление, запрет смены workspace, роли и отказ чужому/отозванному участнику.
- Добавлен GitHub Actions workflow для v2. Его результат проверяется отдельно от локального запуска.
- Первоначально перенесённая версия Zod 4.3.6 попала под advisory GHSA-mrhx-c7xc-m3w5 в npm audit. В v2 обновлена до исправленной 4.6.7; после обновления TypeScript и все 38 тестов прошли повторно. `npm audit --prefix v2 --omit=dev --json` сообщил 0 известных уязвимостей production-зависимостей v2. Это не доказывает отсутствие всех уязвимостей приложения.

## Существующий flowix-mvp

`npm ci --ignore-scripts` выполнился. Первая сборка расширения остановилась из-за отсутствующего optional-пакета `@rollup/rollup-linux-x64-gnu` в Linux-установке. После локальной установки пакета версии 4.59.0 без сохранения зависимостей расширение собралось. Этот повторный npm install также пересогласовал локальные node_modules в пределах старых диапазонов версий; повтор не считается доказательством идеальной воспроизводимости исходного lockfile.

Web `next build` успешно скомпилировал приложение, проверил TypeScript и сгенерировал маршруты. Предупреждения: устаревающее имя middleware и автоматический патч SWC в lockfile. До build отдельный tsc не видел декларацию PNG, потому что Next ещё не создал next-env.d.ts; в production build эта ошибка не повторилась. Автоматические изменения старого lockfile не включены в ветку.

Это подтверждает возможность сборки существующего кода, а не корректность авторизации, записи или командного использования. Переписывание не обосновывается тем, что старый проект якобы вообще не запускается.

## Не проверено

Реальный Chrome capture и установка расширения, UI, сетевые гонки в браузере, адаптер IndexedDB, фактический SHA-256/декодирование изображений, серверный API v2, RLS, production, доставка приглашений, оплата и восстановление резервной копии. Тест compare-and-swap использует тестовый атомарный store; реальную транзакцию хранилища нужно проверить на следующем этапе.

Новая версия не развёрнута. Изменения базы, рабочего хранилища и текущего сайта не выполнялись.
