# Контракты v2

**HTTP endpoints пока не реализованы.** Здесь зафиксирован целевой контракт. Реальные исполняемые проверки находятся в `packages/core/src/`.

## Формат флоу

`schemaVersion: 1`, UUID `id` и `workspaceId`, `title`, упорядоченные `frames`, `transitions`.

Кадр содержит UUID, image metadata (UUID asset, SHA-256, размеры, байты, PNG/JPEG), очищенный source URL и время. Связь содержит `fromFrameId`, `toFrameId`, hotspot `{x,y,width,height}` в диапазоне 0..1 относительно изображения. Ссылка ведёт только к следующему кадру. Поле с неизвестным назначением отклоняется, а не сохраняется бесконтрольно.

Текущие технические пределы foundation: 200 кадров, 160 символов заголовка, 10 MiB на изображение, 8192 px на сторону, 24 MP. Это защитные ограничения, не тарифный план и не результат расчёта себестоимости.

`parseFlow` допускает неполный черновик. `requirePlayableFlow` требует связи для каждой соседней пары. `followHotspot` возвращает следующий кадр только при попадании в область клика.

## Целевые HTTP операции

| Операция | Назначение | Критическое условие |
| --- | --- | --- |
| POST `/api/v2/workspaces/:id/flows` | Создать flow | Проверенное членство editor/owner |
| POST `/api/v2/flows/:id/captures` | Добавить очищенный кадр | capture ID, хэш, квота, транзакция, контроль принадлежности asset |
| PATCH `/api/v2/flows/:id/draft` | Изменить порядок, подписи, связи | Ожидаемая revision, конфликт при устаревшей версии |
| POST `/api/v2/flows/:id/publish` | Зафиксировать версию | Все переходы корректны, изображения проверены |
| GET `/api/v2/flows/:id` | Открыть flow | Текущее членство в workspace |
| POST `/api/v2/workspaces/:id/invitations` | Пригласить коллегу | Owner, ограниченный срок приглашения |
| DELETE `/api/v2/workspaces/:id/members/:userId` | Отозвать доступ | Owner, нельзя удалить последнего owner |

Принципы ответа: 400 — некорректный payload, 401 — личность не установлена, 403/404 — нет доступа согласно выбранной политике сокрытия объектов, 409 — revision/idempotency conflict, 413 — размер, 422 — недопустимое изображение, 429 — квота/частота. Внутренние ошибки БД наружу не возвращаются.

## Граница доверия core

`canAccessWorkspace` — чистая политика, **не проверка JWT**. Получает уже проверенную сервером личность и актуальную запись membership из БД. Передача произвольной роли из запроса нарушает контракт.

`updateSession` требует атомарный `SessionStore.compareAndSwap`. Тестовый store проверяет поведение при конфликте, но не заменяет реальный адаптер IndexedDB/PostgreSQL. Изображение проверяется декодером и хэшируется адаптером до commit. SHA-256, MIME и byteLength из клиента не являются доказательством подлинности байтов.
