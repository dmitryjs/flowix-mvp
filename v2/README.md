# Flowix v2

Перезапуск Flowix: собственная библиотека веб-сценариев для продуктовых команд.

Статус: **техническая основа, не готовое расширение и не запущенный SaaS**. Реализованы общие контракты, проверка линейного флоу, переход по hotspot, модель состояния записи и политика доступа. Браузерный адаптер, IndexedDB, HTTP API, база, интерфейс и оплата ещё не подключены.

## Проверка основы

Нужен Node.js 24. Из корня репозитория:

```bash
npm ci --prefix v2 --ignore-scripts
npm run check --prefix v2
```

Тесты запускают TypeScript через встроенную поддержку Node.js. TypeScript отдельно проверяет типы. Версии зависимостей зафиксированы, `v2/package-lock.json` хранится в Git. В этой основе нет ключей, внешних запросов, подключения к существующей базе или миграции старых данных.

## Структура

`packages/core/src/contracts.ts` — формат данных и ограничения.

`packages/core/src/recorder.ts` — резервирование/завершение захвата, остановка, восстановление и контракт атомарного сохранения.

`packages/core/src/replay.ts` — нормализация областей клика и линейное воспроизведение.

`packages/core/src/access.ts` — правила ролей для уже проверенной сервером личности.

`tests/` — проверки граничных случаев и регрессий, найденных в старом коде.

Существующие `apps/` остаются прежней версией. `v2/` — временная изолированная зона новой реализации в отдельной ветке. После готовности полного сценария новая структура заменит старую отдельным изменением; два продукта не будут поддерживаться бессрочно.
